- [`features`](topics/features.md): Choose an authoring surface before introducing a fallback.
- [`overview`](topics/overview.md): Navigate the main public help topics.

- [`workflow-rules`](topics/workflow-rules.md): Review preferred authoring practices.
- [`capabilities`](topics/capabilities.md): Check support boundaries.

## Open a focused guide

- When a page names a handle such as `playbook.workflows` or `workflow.step.profile_switch`, run `ordo-help describe <handle>` to read its focused guide.
- Use `ordo-help search <words>` when you know the goal but not the handle; search results include the exact focused-help command.

## Navigation commands

These are interactive discovery surfaces in `ordo-help`, so they are listed here as commands rather than static pages.

- `snippet-coverage` — Inspect which public handles do and do not publish canonical verified snippets
- `operation` — Inspect one public operation by reference
- `describe` — Resolve a supported public topic
- `search` — Search topics, contract facts, and operation references
